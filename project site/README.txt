Preview: Open index.html in a web browser. Navigation links connect all three pages.

Publish with GitHub Pages:
1. Create a PUBLIC GitHub repository (for example, my-style-edit).
2. Upload all four website files to the repository root.
3. Go to Settings > Pages > Build and deployment, choose Deploy from a branch, main, /(root), and Save.
4. After publishing, the URL usually looks like https://YOUR-USERNAME.github.io/my-style-edit/ . Confirm the actual URL from GitHub Pages before submitting.
5. Paste the real published URL into the Milestone 5 Word document.
